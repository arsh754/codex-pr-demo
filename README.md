# Flowboard

Flowboard is a polished, responsive project dashboard built with plain HTML, CSS, and JavaScript. It was created as a practical GitHub pull-request workflow demo.

## Features

- Responsive Kanban board with four project stages
- Task search and live task-count updates
- Task creation modal
- Light and dark themes, remembered in browser storage
- Keyboard shortcut: `Cmd/Ctrl + K` focuses search
- No build tools or dependencies required

## Run locally

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000` in a browser.
